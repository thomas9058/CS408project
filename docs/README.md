# Full-Stack Web Application

This repository contains a Dockerized Django web application built with Python, Django, and SQLite. It includes configuration and documentation for setting up, running, testing, and debugging the application locally using Docker.

## Technology Stack
- Backend Technology Stack
    - Backend Language: Python 3.12
    - Backend Framework: Django
    - Application Server: Django development server
    - Database: SQLite
- Frontend Technology Stack
    - Templates: Django Templates 
    - UI/UX Framework: Bootstrap 5
- Testing Frameworks
    - Unit / Integration Testing: pytest + pytest-django
- Debugging Tools
    - Containerized Debugging: debugpy
